# Roadmap

Saito Consensus was invented in the Spring of 2017. Early development focused on assembling a javascript prototype to confirm that routing work mechanisms could be technically implemented. Work building the network began in earnest in 2018, with an initial token sale following in 2021 to raise funding for further development.

The network is now in a stable state, with a user-facing javascript client, a backend full-node coded in the Rust programming language, and a suite of useful applications that power everything from games to social media and communication apps. Our community is actively update existing applications, building new ones, and using the network to buy and sell the sorts of on-chain digital assets that are only possible on Saito.

If you have questions or would like to get involved in development, please join us on [RedSquare](https://saito.io/redsquare) anytime!
